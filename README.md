# 英语练习室 · 使用说明

一个可以**装到手机桌面、离线可用**的英语练习 App。
两块内容：六级 22 天冲刺 + 口语/听力长期训练。

---

## 一、手机上用（推荐）

看 **`手机安装说明.md`**。

一句话版本：把文件夹上传到 GitHub Pages 拿到 https 地址 → 手机 Safari/Chrome 打开 → 添加到主屏幕。
装好后就是全屏 App，有图标，不用电脑，没网也能用。

> 为什么不能直接双击 html？
> 录音需要麦克风，而浏览器只在 **https** 或 **localhost** 下才给麦克风权限。
> 电脑上靠 `start.bat` 起一个本地服务解决；手机上靠 https 解决。

---

## 二、电脑上预览

1. 双击 `start.bat`
2. 浏览器打开 `http://127.0.0.1:8765/index.html`
3. 用 Chrome 或 Edge（录音和语音转写需要）

## 三、里面有什么

| 页面 | 作用 |
|---|---|
| **总览与评估** | 四级分数逐项拆解、诊断、考试倒计时 |
| **22 天冲刺计划** | 每天 4–5 个任务，可勾选，进度自动保存 |
| **口语长跑路线** | 四阶段（敢开口 → 说满 2 分钟 → 讨论 → 流利） |
| **口语陪练室** | 18 道题（4 个难度）、准备 15 秒 + 作答 90 秒计时、录音、转写、四维自评 |
| **跟读纠音** | 15 组句子，练音素、连读弱读、意群节奏 |
| **复盘与记录** | 口语记录、周复盘、数据导出/导入 |
| **听力练习 / 人机对话** | 点一下就朗读一段话再出题；5 个场景的多轮英文对话，每轮给更自然的说法 |
| **单词测试** | 380 个六级高频词，三种考法（英→中 / 听音辨词 / 中→英），答错自动进错题本 |
| **听力记忆训练场** | 独立页面，专治"听懂了记不住"：速记系统、记忆阶梯、学科背景补齐 |

## 四、每天怎么用

**考前 22 天：90–120 分钟，口语 0 分钟**

1. 「计划」页做当天的「必做」项（约 50 分钟，其中听力占一半）
2. 「单词」页做 20 个词（约 10 分钟），错词自动进错题本
3. 听力卡住时去「听力记忆训练场」，用速记系统 + 记忆阶梯（约 15 分钟）
4. 睡前在「复盘」记一句话：今天丢的分属于哪一类

**时间紧的日子（最低配 40 分钟）**

1 篇听力 + 20 个单词。这两项不能断，写译和阅读可以砍。

**考完试之后（12/13 起）：30–40 分钟**

1. 「口语」抽一题，录 90 秒
2. 回听，打四维分，写「这次最大的问题」和「下次只改一件事」
3. 同一题再录一遍——第二遍的差别就是进步
4. 10 分钟跟读，或一段 6 Minute English

## 五、文件

| 文件 | 作用 |
|---|---|
| `index.html` | 主应用（计划、单词、口语、跟读、复盘） |
| `interactive.html` | 听力练习（自动朗读 + 12 题）+ 人机对话（5 场景） |
| `listening.html` | 听力记忆训练场 |
| `vocab.js` / `vocab-ui.js` | 380 词词库 + 测试逻辑 |
| `manifest.webmanifest` | PWA 清单，决定图标、名称、启动方式 |
| `sw.js` | Service Worker，让 App 离线可用 |
| `icons/` | 图标（192/512，含 Android 自适应版本） |
| `server.py` / `start.bat` | 电脑本地预览用 |
| `手机安装说明.md` | 装到手机的完整步骤 |
| `english-practice.zip` | 一次性上传用的打包文件 |

## 六、数据

- 全部存在本机浏览器 localStorage，不上传
- 换浏览器 / 清缓存 / 删 App 会丢，**每周日导出一次 JSON**
- 录音只存在当前页面里，刷新就没了。想留存用手机录音机

---

## 七、一个提醒

页面里的计划是通用模板，不必 100% 执行。
**判断标准只有一个：这周你有没有比上周多说 60 秒、多听懂一段。**
计划是脚手架，不是 KPI。
